# Getting started

This project has been created to support developing tools under the TQL 4-5 process.

# Process

## 1. Create a Plan

To start, create a plan for the tool you want to develop. You can use the User Story here to track this effort:

#${create_plan_work_item_url}

To create the plan:

1. Create a new branch in the `Plans` repo.
1. Publish this branch in the `Plans` wiki.
1. Use the newly published branch to add plan content to the Plans wiki.
1. Once ready for review, create a pull request against the branch in the `Plans` repo. The pull request may require approval from the team before merging.

## 2. Create Tool Requirements

First, find the imported Tool Operation Requirements (TOR) in the project backlog. From these TORs, you can create new Tool Requirements using the Tool Requirements work item type.

To track this effort, you can use the User Story here:

#${create_new_requirements_work_item_url}

## 3. Review Tool Requirements

Once the Tool Requirements are created, you can start a review using the Review work item here:

#${review_work_item_url}

Before starting the review, ensure that all Tool Requirements under review are linked to the Requirements Review work item for traceability.

## 4. Design the Tool

After that, don't forget to create a design for the new tool. You track this work using the User Story here:

#${create_design_work_item_url}

And store the tool design in the Design story here:

#${design_work_item_url}
